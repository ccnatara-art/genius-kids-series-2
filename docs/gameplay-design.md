# Gameplay MVP

- 5 dunia, masing-masing 3 misi.
- Setiap misi memiliki 3 pertanyaan/tantangan.
- Junior melihat 2 pilihan, Explorer 3 pilihan, Champion 4 pilihan.
- Tidak ada timer wajib, pengurangan bintang, atau game over.
- Anak boleh mengulang misi.
- Bintang terbaik per misi disimpan secara lokal.
- Misi berikutnya terbuka setelah misi sebelumnya selesai.

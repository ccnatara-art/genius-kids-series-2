# UI Guidelines

- Gaya: colorful 2D cartoon, hangat dan ramah anak.
- Background: warm cream `#FFF9F1`.
- Primary: purple `#7057D9`.
- Accent: coral `#FF8068`, yellow `#FFD166`, mint `#69D6B1`, blue `#72B9F5`.
- Text: dark navy `#29334D`.
- Rounded cards: 20–30px.
- Tombol dan area interaksi nyaman disentuh.
- Ilustrasi karakter dan dunia menggunakan SVG lokal original.
- Animasi singkat, tidak berkedip cepat, dan menghormati `prefers-reduced-motion`.
- Jangan mengandalkan warna saja untuk membedakan jawaban; gunakan ikon dan label.
